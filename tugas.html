Coba berikan contoh dan penjelasan terhadap 3 pemangku kepentingan / stakeholder terhadap pengelolaan data untuk aplikasi cloud pada bidang

  1. Reservasi Hotel,
  2. SIM Rumah Sakit,
  3. Perbankan.

Berikut adalah penjelasan dan contoh penerapannya pada tiga aplikasi SaaS di masing-masing bidang:

1. Aplikasi Reservasi Hotel (SaaS Property Management System / Booking Engine)

  • Pengendali Data: Pihak Manajemen Hotel / Properti. Hotel menentukan data apa saja yang wajib diisi saat check-in atau reservasi, lama penyimpanan data tamu, serta kebijakan privasi dan pemasaran.
  • Pemroses Data: Penyedia SaaS Reservasi Hotel (beserta penyedia cloud infrastructure di baliknya). Mereka menyediakan aplikasi, basis data, enkripsi, dan backup untuk memproses transaksi kamar sesuai konfigurasi hotel tanpa menentukan tujuan bisnis data tersebut.
  • Pemilik Data: Tamu Hotel / Pelanggan (seperti nama lengkap, nomor identitas/KTP/paspor, kontak, riwayat menginap, dan preferensi kamar).

2. SIM Rumah Sakit (SaaS Hospital Information System / Electronic Medical Record)

  • Pengendali Data: Manajemen Rumah Sakit / Fasilitas Pelayanan Kesehatan. Rumah sakit bertanggung jawab penuh atas keputusan regulasi kesehatan, hak akses tenaga medis, kerahasiaan rekam medis, dan tujuan pengolahan data pelayanan pasien.
  • Pemroses Data: Penyedia SaaS SIM Rumah Sakit (dan mitra cloud yang memenuhi standar keamanan data kesehatan). Mereka mengelola ketersediaan sistem, keamanan transmisi dan penyimpanan data, serta pemeliharaan aplikasi sesuai kontrak dan instruksi rumah sakit.
  • Pemilik Data: Pasien (sebagai subjek data pribadi dan rekam medis, mencakup identitas, riwayat diagnosis, hasil laboratorium, alergi, dan riwayat tindakan medis).

3. Aplikasi Perbankan (SaaS Core Banking / Loan Origination / Payment & Compliance Platform)

  • Pengendali Data: Bank / Lembaga Jasa Keuangan. Bank menentukan kebijakan pemrosesan data nasabah, manajemen risiko, pelaporan regulator keuangan, serta standar keamanan dan retensi data sesuai hukum perbankan.
  • Pemroses Data: Penyedia SaaS Perbankan (dan penyedia cloud yang ditunjuk). Mereka menjalankan perangkat lunak, komputasi, dan penyimpanan data transaksi atau proses bisnis tertentu berdasarkan perjanjian layanan (SLA dan DPA) serta arahan bank.
  • Pemilik Data: Nasabah Bank (baik nasabah perorangan maupun korporasi, meliputi data identitas, rekening, saldo, riwayat transaksi, dan informasi kelayakan kredit).
