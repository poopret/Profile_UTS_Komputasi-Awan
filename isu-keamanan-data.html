Isu Keamanan Data pada Aplikasi SaaS

Pemangku kepentingan beserta isu keamanan data utamanya pada tiga bidang aplikasi SaaS: reservasi hotel, SIM rumah sakit, dan perbankan.

Pemangku kepentingan dan isu keamanan data utama pada tiga bidang aplikasi SaaS
Bidang Aplikasi SaaSPemangku KepentinganPihak Terkait (Stakeholder)Isu Keamanan Data Utama
1. Reservasi HotelPengendali Data Manajemen Hotel / Properti Penyalahgunaan akses staf (insider threat) dan retensi salinan KTP/kartu tamu berlebihan.
Pemroses Data Vendor SaaS Reservasi & Cloud Kebocoran data antar-tenant (cross-tenant) dan celah keamanan API ke OTA / payment gateway.
Pemilik Data Tamu Hotel / Pelanggan Phishing berkedok konfirmasi booking dan pencurian identitas saat pre-check-in.
2. SIM Rumah SakitPengendali Data Manajemen Rumah Sakit / Faskes Hak akses berlebihan (over-privileged) dan penggunaan akun bersama (shared account).
Pemroses Data Vendor SaaS SIMRS & Cloud Gangguan layanan akibat ransomware/downtime dan paparan data medis (PHI) saat pemeliharaan.
Pemilik Data Pasien Tersebarnya riwayat penyakit sensitif tanpa izin dan risiko perubahan data alergi/resep obat.
3. PerbankanPengendali Data Bank / Lembaga Jasa Keuangan Pelanggaran lokasi penyimpanan data (data residency) dan kebocoran data lewat mitra pihak ketiga.
Pemroses Data Vendor SaaS Perbankan & Cloud API hijacking pada transaksi, supply chain attack pada pembaruan SaaS, dan lemahnya manajemen kunci enkripsi.
Pemilik Data Nasabah Bank Account takeover (pencurian OTP / bypass e-KYC) dan penyalahgunaan identitas untuk pinjaman ilegal.
