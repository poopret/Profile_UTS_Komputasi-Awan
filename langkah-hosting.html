Langkah Hosting Website dengan GitHub

Cara menaruh website di internet secara gratis memakai GitHub Pages.

Kotak kuning menandai bagian yang diklik. Klik atau ketuk gambar untuk memperbesar.

  1. 1

    Buka GitHub

    Buka github.com di browser, lalu klik Sign in di pojok kanan atas.

  2. 2

    Login

    Isi username atau email dan password, lalu klik Sign in. Belum punya akun? Pilih Create an account.

  3. 3

    Buka Repositories

    Klik foto profil di pojok kanan atas, lalu pilih Repositories.

  4. 4

    Buat repositori baru

    Di halaman Repositories, klik tombol hijau New.

  5. 5

    Isi data repositori

    Isi Repository name dan Description, pastikan Public, lalu klik Create repository. Nama repositori jadi bagian dari alamat websitemu, jadi tulis tanpa spasi.

  6. 6

    Buka menu upload

    Di halaman repositori, klik Add file, lalu pilih Upload files.

  7. 7

    Unggah file website

    Pilih atau seret semua file website: halaman .html, style.css, dan folder assets. Setelah itu klik Commit changes.

  8. 8

    Aktifkan GitHub Pages

    Buka tab Settings, pilih Pages di menu kiri. Pada bagian Branch, ubah None menjadi main, lalu klik Save.

  9. 9

    Tunggu sampai aktif

    Tunggu sebentar sampai muncul Your site is live at … dan tombol Visit site. Kalau belum muncul, muat ulang halaman.

  10. 10

    Website sudah online

    Copy link dari kolom alamat browser. Bentuknya https://<username>.github.io/<nama-repositori>/ dan bisa dibuka siapa saja, gratis.
