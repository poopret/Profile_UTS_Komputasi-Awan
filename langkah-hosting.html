Langkah Hosting Website dengan GitHub

Cara menaruh website di internet secara gratis memakai GitHub Pages — dari login sampai websitemu bisa dibuka online.

  • 10 langkah
  • Gratis
  • Cukup lewat browser

Tahap 1Masuk ke GitHub

  1. 1

    Langkah 1 dari 10

    Buka halaman GitHub

    Buka github.com di browser. Ini halaman pertama GitHub sebelum login. Klik Sign in di pojok kanan atas untuk melanjutkan.

  2. 2

    Langkah 2 dari 10

    Login ke akun GitHub

    Di halaman login, isi data akunmu lalu tekan tombol hijau. Belum punya akun? Pilih Create an account di bagian bawah.

    1. 1Isi Username or email address
    2. 2Isi Password
    3. 3Tekan Sign in

Tahap 2Buat repositori

  1. 3

    Langkah 3 dari 10

    Masuk ke daftar repositori

    Setelah login, kamu berada di beranda (Dashboard). Buka menu profil, lalu masuk ke repositori.

    1. 1Klik foto profil di pojok kanan atas
    2. 2Pilih Repositories
  2. 4

    Langkah 4 dari 10

    Buat repositori baru

    Di halaman Repositories, tekan tombol hijau New.

  3. 5

    Langkah 5 dari 10

    Isi data repositori

    Beri nama repositori dan isi deskripsinya, pastikan dibuat Public, lalu tekan Create. Nama repositori nanti menjadi bagian dari alamat websitemu, dan hanya boleh berisi huruf, angka, titik, strip, atau garis bawah (tanpa spasi).

    1. 1Isi Repository name
    2. 2Isi Description
    3. 3Pastikan Choose visibility = Public
    4. 4Tekan Create repository

Tahap 3Unggah file website

  1. 6

    Langkah 6 dari 10

    Buka menu upload file

    Di halaman repositori yang baru dibuat, buka menu Add file lalu pilih Upload files.

    1. 1Klik Add file
    2. 2Pilih Upload files
  2. 7

    Langkah 7 dari 10

    Unggah semua file website

    Seret (drag and drop) semua file website ke halaman upload, atau pilih lewat jendela Open. Pastikan semuanya ikut: halaman .html, style.css, dan folder assets. Setelah itu tekan Commit changes.

    1. 1Pilih semua file website
    2. 2Tekan Commit changes

Tahap 4Aktifkan GitHub Pages

  1. 8

    Langkah 8 dari 10

    Atur GitHub Pages

    Buka tab Settings di repositori, pilih Pages di menu kiri. Pada bagian Branch, ubah None menjadi main, lalu tekan Save.

    1. 1Buka tab Settings
    2. 2Pilih Pages
    3. 3Ubah None menjadi main
    4. 4Tekan Save
  2. 9

    Langkah 9 dari 10

    Tunggu sampai website aktif

    Tunggu sebentar sampai muncul keterangan Your site is live at … beserta tombol Visit site. Itu tanda websitemu sudah online. Kalau belum muncul, tunggu sebentar lalu muat ulang halaman.

Tahap 5Website online

  1. ✓

    Langkah 10 dari 10Selesai

    Copy link — website sudah online

    Klik Visit site atau copy link dari kolom alamat browser. Link ini sudah bisa dipakai secara online oleh siapa saja, gratis.

    Bentuk linknya: https://<username>.github.io/<nama-repositori>/
